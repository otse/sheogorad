Area changes (POST /api/areas/:name/changes)

Keeps a client-side map of { id: version } for every building and npc it has already seen in the area, and sends that map back on every poll. The server only returns the buildings/npcs whose version moved past what's in the map — nothing else is resent, and the client never has to diff anything itself. 

Pick an area and click Watch changes…
